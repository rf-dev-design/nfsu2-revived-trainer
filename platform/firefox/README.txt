U2 Revived Trainer — Firefox build

This build is unsigned, so Firefox loads it as a temporary add-on:

  1. Open about:debugging#/runtime/this-firefox
  2. Click "Load Temporary Add-on…" and pick manifest.json in this folder
     (or the .xpi / .zip file).
  3. Reload nfsu2.xyz and press F2 in the game.

Temporary add-ons are removed when Firefox closes. Needs Firefox 128 or newer.
